# Ozmo Landing Page Template

A clean, responsive landing page template based on the [Ozmo MOTORSPORT](https://www.ozmo-motorsport.co.uk) design.

## Features
- **Responsive Design:** Built using Bootstrap to ensure compatibility across devices.
- **Modular Structure:** Uses PHP includes for reusable components (header, footer, etc.).
- **Interactive Elements:** Includes support for:
  - Parallax Sliders
  - Owl Carousel
  - Cookie Consent management
- **Customizable:** Easy to update styles and configurations via dedicated CSS/Config files.

## Project Structure
- `site-template/`: Main directory containing the website files.
  - `includes/`: Reusable PHP snippets (header, footer, config).
  - `css/`: Stylesheets including themes and plugins.
  - `js/`: JavaScript files, including plugins and app logic.
  - `images/`: Asset storage.
- `config-main-tp15.php`: Main configuration settings for the site.

## Getting Started

1. **Requirements:**
   - A PHP-enabled web server (e.g., Apache, Nginx, XAMPP, MAMP).
   - Ensure the server is pointing to the `site-template/` directory as the document root.

2. **Installation:**
   - Clone the repository to your server's web directory.
   - Ensure permissions are set correctly for your web server to read the PHP files and static assets.

3. **Configuration:**
   - Modify the files in `site-template/includes/` to update site-wide headers, footers, or navigational elements.
   - Adjust `config-main-tp15.php` for site-specific settings.
